# Sayac-App-42621 — Ürün Gereksinim Dokümanı (PRD) ## 1. Proje Genel Bakışı **Proje Adı:** Sayac-App-42621 **Proje Türü:** Basit Sayaç Uygulaması (Web SPA) **Platform:** Web (React 18 + Vite + Tailwind CSS) **Özet:** Kullanıcının sayı değerini artırma, azaltma ve sıfırlama işlemlerini yapabildiği tek ekranlı, minimalist sayaç uygulaması. ## 2. Fonksiyonel Gereksinimler ### 2.1 Temel Özellikler - Sayı Görüntüleme: Büyük ve okunaklı. - Arttır Butonu: +1 - Azalt Butonu: -1 - Sıfırla Butonu: 0'a eşitler. ### 2.3 Edge Case'ler - Minimum değer 0. 0'da azalt butonu devre dışı kalır. ## 4. UI/UX Gereksinimleri - **Stil:** Minimalist, temiz, modern. - **Renk Paleti:** Karanlık tema (Kullanıcı isteği üzerine), kontrastlı butonlar. - **Tipografi:** Büyük, bold sayaç rakamı. - **Layout:** Ekran ortalanmış, dikey düzen. ## 6. Ekranlar (Screens) 1. Ana Sayaç Ekranı 2. Boş Durum (0 değeri) 3. Sınır Durumu (0'da butonun pasif hali)
